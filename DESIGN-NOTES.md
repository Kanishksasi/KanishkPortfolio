# Personal Studio Design

The recommended direction is a personal studio: Kanishk's name, portrait, interests, and real products introduce him, then scrolling reveals selected work in distinct chapters. The complete project collection and full background have their own pages.

## Research

- [Bruno Simon](https://bruno-simon.com/): a Three.js world makes exploration memorable and demonstrates technical craft. This portfolio adopts an interactive scene featuring Kanishk's actual products and portrait.
- [Brittany Chiang](https://brittanychiang.com/): projects, experience, and evidence are directly accessible. Work and Journey pages make this material easy to review.
- [Rauno Freiberg](https://raunofreiberg.com/): restrained typography and thoughtful interactions informed the precise controls and transitions.
- [Academy admissions](https://theacademysf.com/admissions): admission is heavily weighted toward proof of work. Project artifacts remain prominent throughout the site.
- [Academy FAQ](https://theacademysf.com/faq): applicants should write their own story. Existing personal text and user-supplied descriptions are preserved; personal project reflections still need Kanishk's words.

This is a design recommendation tailored to Kanishk's work, not a claim that any visual style guarantees admission.

## Experience

The 3D introduction uses Three.js, local images, and a bundled script. The scene supports mouse rotation, keyboard rotation, project clicks, and pause/play. System reduced-motion preferences pause it by default. It stops continuous rendering when off-screen. A portrait fallback and ordinary links remain available without WebGL or JavaScript.

The home page contains selected work, About, journey highlights, online work, and contact links. Work contains all 13 projects and category filters. Journey contains complete experience, education, training, languages, and awards. Individual project pages retain artifacts, screenshots, personal build notes where provided, and next-project navigation.
